## Review — warm start (ADR-0029 P1), permissive green (0031/0033), routed lookahead (0032), gridlock escape (0034)

Verified against the repo: keyframe v5 writer/reader gates are consistent (empty-queue count now explicit, short-read checked, trailing-bytes check intact); `sigPermissive` mirrors `sigState`'s phase lookup exactly; `fastForward`'s tick rounding (`at/dt+0.5`) matches `onSnapshot`/`send`; no map iteration, wall clock, or RNG in any new kernel path; `strandStuck`/`resetStuckBehind` sweep in fixed order; old recordings replay with `StrandAfterS=0` from their recorded spec (escape inert on old records); scenario runs get the 300 s default via `DefaultParams`.

### Blocker

**1. Warm start + demand director double-injects (or double-expires) arrivals near the cut — silently breaking ADR-0029's own bit-exact criterion.**
The warm run's `Contract` starts with an empty verb-dedup map (`engine/natsio/contract.go:764`), and `EnqueueSpawn`'s duplicate check covers only directives still *live in the queue* (`engine/director.go:154-161`). The first snapshot a warm director can react to is published only **after** `Step(T+1)` (`engine/natsio/run.go:227`; nothing is published between restore and the loop). So a directive restored in `dirQueue` with `EarliestTick == T+1` executes before the director can send anything; the director then resends that same RequestID (`fastForward` skips only arrivals `<= startTick`, `engine/natsio/demand/director.go:277`, and the (T, T+lead] window is resent by design), the fresh contract has no memory of it, the queue no longer holds it → accepted → a **second vehicle** spawns (EarliestTick well inside the 600-tick hold window, `engine/director.go:49`). The same happens for any directive whose execution races ahead of verb delivery; in batch mode (pace 0) the duplicates instead expire and inflate `DirExpired`. Either way the warm run diverges from the cold run it claims to continue, with no error. This is the shipped `serve -state-in` path for every scenario with demand (i.e., all Chicago runs); `TestRunLiveWarmStartIsBitExact` uses the spawner only, so no test covers it. Fix shape: seed the contract's verb-dedup map from the restored `dirQueue`'s RequestIDs at warm start (the contract is built before the first Step, while the queue is intact) — in-flight-at-dump verbs stay accepted, already-restored ones dedup; add a RunLive warm-start test with an attached director.

### Should-fix

**2. `RunLive` accepts `InitialState` + `Observer` (engine/natsio/run.go:103).** serve refuses `-state-in -metrics-out`, but the library seam doesn't; the metrics kernel's "attach before first Step" failure then surfaces after the broker/registry are up with an error that reads like an ordering bug. One early check in `RunLive` matches the flag-level refusal.

### Nits

- `engine/rightofway.go:454` — `cls := e.foeSignalClass(foe)` depends only on `foe` but is recomputed per stopped vehicle per `Prevs` lane; hoist above the loop.
- ADR-0034 ("a red light is never a trigger") slightly overclaims: a head stopped at red whose routed box is *also* blocked for the full 300 s does strand — the discriminator is `boxBlocked`, which red doesn't preclude. `TestEscapeIgnoresOrdinarySignalQueue` uses an empty exit, so it can't distinguish. Behavior is arguably right (SUMO teleports there too); the ADR sentence isn't.
- Test leftovers: `_ = x` (permissivedeadlock_test.go, `TestPermissiveGreensDoNotDeadlock`) and `_, _ = link0, link1` (permissivegreen_test.go, `TestSigPermissiveFollowsThePhase`).

### Questions

- ADR-0031 makes a permissive approach minor via `RowNone != RowMajor` — if netimport ever emits a signalised internal lane with `Row: major`, its permissive phase silently won't yield to crossing foes (`rowConflict`'s `minor` guard). Is `RowNone`-on-signalised an import invariant worth asserting at net load?
- A permissive ego still yields to a foe *rolling toward its own red* (the moving-foe braking check at `engine/rightofway.go:473` predates `foeSignalClass`, which only classifies stopped foes). Intended, or the same "yielding to a vehicle that cannot commit" drag one tick earlier?
