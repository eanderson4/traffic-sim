## Should-fix

1. **overpass2osm.py:349-354 — "real nodes win over synthesis" is element-order-dependent.** A mixed-shape way (both `nodes` and `geometry`) that appears *before* its node elements synthesizes coords (`ref not in real_nodes` is vacuously true), and the real node is later emitted too → duplicate `<node id=…>` in the XML (synth emission at line 370 never re-checks `real_nodes`). The docstring's mixed-shape guarantee only holds when nodes precede ways. Filter `synth_nodes` against `real_nodes` at emission.

2. **osm-stop-nodes.py:145-146 — way-split nodes count as junctions.** OSM routinely splits one road into consecutive ways; the shared end node has ≥2 distinct way ids but is not an intersection. Consequences: (a) a stop node sitting at a split point takes the `holding >= 2` branch (line 165-167) → spurious `allway_stop` at a 1-in/1-out through node; (b) walks terminate at the first split point (line 180-183), retyping a node upstream of the real intersection — stop control lands mid-road. Doesn't break netconvert (every shared node is a junction in the no-join net), but misplaces control.

3. **osm-stop-nodes.py:191 — arm aggregation conflates a through way's two approaches into one arm.** T-junction: through way A, ending way B. Stops on one A-approach and on B give `arms == {A, B} == incident` → `allway_stop`, though the opposite A-approach is uncontrolled. A per-direction arm key (way id + walk sign) would fix it.
