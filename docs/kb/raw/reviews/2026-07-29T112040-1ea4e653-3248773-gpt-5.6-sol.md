- **blocker** `engine/natsio/run.go:195` — Warm start never publishes the restored tick’s snapshot before releasing the attach barrier. The first snapshot is only published after `e.Step()` at `engine/natsio/run.go:223`, so the embedded driver cannot produce the tick-T response needed for T+1. Existing vehicles coast/use stale persistent axes for one tick, violating ADR-0029’s bit-exact acceptance criterion. The tests only exercise controller-free runs.

- **blocker** `engine/warmstart.go:203` — The sidecar is not bound to the state contents. Matching tick and byte length do not prove that two files belong together; a different state at the same tick and size passes and is restored using the sidecar’s network fingerprint. Store and verify a digest of the state bytes.

- **blocker** `engine/warmstart.go:121` — The guard validates only lane indices, but keyframes also encode vehicle and queued-directive types by ordinal (`engine/keyframe.go:249`). Reordering the scenario type list on the same network silently turns existing vehicles into different types. The sidecar must bind every index-based table, at minimum ordered vehicle-type identity.

- **blocker** `engine/gridlock.go:152` — `jammedAtJunction` checks only the immediate successor. Vehicles held upstream of a short non-internal boundary stub—explicitly supported by `gateTarget`—never see `next.Internal`, so they can remain permanently gridlocked without the escape firing. Walk to the routed controlled internal lane as the right-of-way gate does.

- **should-fix** `engine/engine.go:451` — `leaderAtFor` clears `HeldTurn` only when the current lane has multiple successors. Real crossing logic consumes it on the first lane boundary regardless, so a single-successor stub followed by a diverge incorrectly applies the turn to that later junction.

- **should-fix** `engine/natsio/run.go:150` — Warm-started runs still publish registry metadata with `started_tick: 0` (`engine/natsio/registry.go:79`) although their first tick/keyframe is nonzero. That makes the public KV contract false and contradicts ADR-0029’s claim that no NATS contract changes are involved.

- **should-fix** `engine/warmstart.go:165` — The claimed pairwise interruption safety is false when overwriting an existing path: the new state is installed before the new sidecar, so a sidecar-write failure leaves the old sidecar beside the new state. Combined with the weak tick/length pairing check, that stale pair may be accepted.
