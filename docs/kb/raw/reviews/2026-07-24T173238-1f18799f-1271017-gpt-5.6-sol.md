- **blocker** `engine/natsio/probe.go:23` / `engine/cmd/demosrv/supervisor.go:294` — A foreign engine running the same static run ID satisfies readiness, even if the spawned child just failed to bind. - **should-fix** `viz/src/main.ts:328` / `viz/src/tssg.ts:196` — Reply chunks and broadcast chunks feed one generation-less accumulator concurrently.
