## Findings

**should-fix — the destinations-by-district report still commits error #4 of this very correction.**
`mkod.py:827-840` / `mkod.py:1225-1248`: `observe` accumulates `rate * v` where `rate` is the post-`pscale`, **pre-shape** flow parameter, and the district table divides these rates by each other. That is exactly the "share computed on rates" and "shape fraction missing" pair the ADR text at ADR-0028 (diff lines 49–64) declares invalid — and this diff is what makes it wrong in practice: once `kennedy-am` (plateau at 1.00, ×1.5) coexists with `freight` (0.90) and `reverse-commute` (0.60), districts fed by peak-shaved flows are overweighted, the `(through)` veh/h figure is a rate no instant sees, and the pinned-share "SHORT by" detector compares against a basis the same commit's own doctrine rejects. Pre-existing code, but the commit's stated purpose is closing this defect class and it leaves the one remaining share report on the old basis. Fix (route `observe` through the same `total_veh` treatment) or at minimum note the exclusion in the ADR correction, which currently reads as "all realized prints fixed."

**nit — phantom stranded entry at 0 veh/h.**
`mkod.py:1062-1065`: `stranded.append(..., emitted)` precedes the `pf is None` continue, so a no-profile portal with no reachable workplace is listed in the stranded WARNING (and counted in `len(stranded)`) at 0 veh/h even though it is never emitted. The tally honors "an absent flow must not appear in a realized total"; the stranded list doesn't. Unreachable with any shipped library (all have a `default`), hence nit.

**nit — the reported "freeway" peak component includes interior injections without saying so.**
`mkod.py:1208-1212`: `fw_pk = peak_rate(cats("freeway", "interior"))` is printed as `freeway {fw_pk}`. Semantically defensible (interior injections are freeway mainline demand), but the header/stderr vocabulary elsewhere keeps "interior" distinct; a reader reconciling this line against the ramp-share line's separately-printed interior peak will double-take. One word ("freeway incl. interior") fixes it.

**question — Knobs header line vs. "reproducing meant guessing the invocation."**
`mkod.py:1278-1286` records the multipliers but not `--corridors`, `--portals`, `--buildings`, `--through-share`/`--freeway-through-share` (the latter two appear on adjacent header lines, the input paths nowhere). Corridor membership decides which flows the ×1.5 Kennedy rule hits, so the header still under-determines the invocation it promises to pin down. Deliberate scope (inputs assumed stable), or worth one more token on the line?
