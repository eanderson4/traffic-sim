## Findings

**Blockers** — none.

**Should-fix**

1. `engine/cmd/demosrv/deploy.go:214-228` — fail-closed asymmetry in `resolveAdminToken`: a whitespace-only **flag** value silently falls through (`TrimSpace(flagVal)` → empty → env fallback → possibly open), while a whitespace-only **env** value fails startup closed. A manifest with `-admintoken="$TOK"` where `$TOK` expands empty/whitespace deploys a public pod with the gate open — exactly the footgun the env path refuses. Symmetric treatment: if `flagVal != ""` but trims empty, error.

**Nits**

2. `engine/cmd/demosrv/deploy.go:258` — `strings.CutPrefix(..., "Bearer ")` is case-sensitive; RFC 7235 auth-schemes are case-insensitive, so `bearer <tok>` 401s. Operator-only clients make this cosmetic.
3. `engine/cmd/demosrv/main.go:120-127` (patch lines 1040-1049) — `-wspublic` validation runs after registry load and the (potentially slow) go-build pre-warm; pure flag validation could fail before the expensive work. Cosmetic startup-latency point only.

**Questions** — none open. Points I checked and am satisfied on:

- **Contract:** no NATS subject or payload changes. The `/api/demos` `ws` field and deep-link `ws=` semantics change only when `-wspublic` is set, and ADR-0020 covers it; the unauthenticated engine ws plane is correctly called out as a go-live gate, not hidden.
- **Shutdown race:** the `closed` latch + double-check in `startGuarded` (supervisor.go:222, 247) is sound under Go's seq-cst atomics — a start either sees `closed` on the re-check or its generation is covered by `shutdownFinal`'s `abortGen` stamp (the stamp's `startGen.Load()` returning N orders it before any `Add()`→N+1). Concurrent `stop()`/`shutdownFinal` clearing `abortGen` under `mu` can't strand an in-flight start, since starts hold `mu`.
- **Corpse handling:** `startIfIdle`'s done-channel check under `mu` plus the reaper now clearing `s.active` (not just the mirror) closes the "autostart gives up on a corpse" hole; the stale reaper's `s.active == a` guard makes the double-clear benign.
- **Gate coverage:** every mutating route (the 7 POSTs) is wrapped; all GETs are read-only (`handleParams`, `handleNet`, `handleOverlay` serve files/JSON, no state change). Autostart bypassing the gate via the supervisor rather than an HTTP exemption is the right shape.
- **Token hygiene:** `stripEnv` on child spawn, constant-time compare with documented length-leak acceptance, no credential echo in the 401 — all fine. Determinism surfaces: untouched (ops-path `time.After`/`time.Now` only; no map iteration feeding serialized output).
