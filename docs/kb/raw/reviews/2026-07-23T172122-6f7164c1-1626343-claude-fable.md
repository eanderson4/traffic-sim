**Verdict: no blockers.** The concurrency design (single Run goroutine owns the engine, ctrl channel for pause/seek, mutex for resume/speed) is sound; determinism discipline holds (map access is keyed, never iterated in sim order; wall clock confined to the pacing wrapper per ADR-0005 §4; seek re-sim is CRC-verified from keyframes); the `-replay` namespace reservation is enforced at all three entry points (`RunLive`, `NewRecorder`, `NewPlayer`) and the ADR-0006 addendum covers both contract-surface decisions. The horizon logic (done → spec.Ticks, else last logged tick) is correct against the registry lifecycle in `registry.go:92-98`.
