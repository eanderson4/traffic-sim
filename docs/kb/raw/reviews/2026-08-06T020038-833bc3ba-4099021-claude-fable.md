## Findings

**should-fix — silent geometry distortion for surviving co-predecessors of an extended internal.** `engine/netimport/consolidate.go:150-168`: the extension applies to every far internal `x` unconditionally, but `x` may retain predecessors that were *not* rewired from the sliver (a via serving connections from a second, non-sliver incoming edge — the exact sharing shape the fan-out fixture demonstrates, with S3 long instead of short). Those movements get their stop line moved upstream and their traversal length inflated by up to 5 m through geometry they never physically cross, and the `SharedExtensions` audit stays silent — it fires only when the second extender is *another sliver*. Bounded (≤ threshold) and rare, so not a blocker, but it's an audit gap in a pass whose stated discipline is "every non-obvious choice is audited": extend the counter to record any extension of an `x` whose live predecessor set exceeds `sPreds`.

**nit — the round-3 audit counter under-counts its own pattern.** `engine/netimport/consolidate.go:226-254` (`countUncontrolledSeamChains`) detects exactly one uncontrolled hop, but `gateTarget` (and the seam gate's blindness) apply through *chains* of uncontrolled internals: `internal → uncontrolled → uncontrolled → controlled` is the same coverage gap and counts 0. If the counter exists to make a future import "say so", it should walk the uncontrolled run, not one hop.

**nit — `succOf` is a generic membership helper** (`consolidate.go:257`) also applied to `rep.SharedExtensions`; the name implies successor semantics it doesn't have. Rename to `contains` when convenient.

**question — the seam gate also fires on *same-junction* controlled internal chains.** `engine/rightofway.go:103` requires only `next.Internal && controlled(next)`, not a junction change, so SUMO multi-part internals (second via carrying the class, same `:J` id) on any pre-existing network now yield mid-box where they previously ran `exitBlocked` only. The ADR addendum's residual-risk statement ("any pre-existing controlled internal→internal chain") reads as covering this, and mid-box yield at an internal junction is arguably the *correct* SUMO semantic — confirming that the same-junction case is intentionally in scope (the comment and tests only discuss cross-junction seams).

No blockers. No determinism, RNG, or wall-clock risks found; the contract change is ADR-covered. The remaining deferred items (idx[s] silent resolution, succs dedupe, test double-assign, /tmp paths) are already recorded in the ADR addenda and correctly triaged under the repo's corrupt-input rule.
