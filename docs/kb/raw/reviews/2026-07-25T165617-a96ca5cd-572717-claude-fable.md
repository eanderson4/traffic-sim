## Review: ADR-0020 demosrv public deployment

**Verified during review:** `go vet` clean; package tests pass, including under `-race`. The gate wraps all seven mutating POST routes and nothing else mutates (`handleParams` at `engine/cmd/demosrv/params.go:173` is read-only — loads scenario, builds JSON). `sup.start` does copy the demo before stamping the run nonce (`supervisor.go:291-297`), so autostart's reuse of `d` across retries is safe as claimed. The viz client uses the advertised ws URL verbatim (`viz/src/config.ts:50`, `encodeURIComponent` in `demos-core.ts`) — no query-appending that a path/query-bearing `-wspublic` would break. No NATS subject or payload changes; the HTTP-API auth change is carried by ADR-0020 as required.

**Concurrency:** I traced the `stopEpoch`/`stopPending`/`closed` interleavings in `startGuarded`/`stop`/`shutdownFinal` (supervisor.go:241-283, 359-378) and found no hole: a stop landing mid-guard either trips `stopPending` (its mark precedes the check) or bumps the epoch after the snapshot (probes abort); `shutdownFinal`'s store-`closed`-first ordering means a start that dodges the latch gets its spawned child killed by the epoch abort under the same mu hold, never orphaned. The mux-level gate placement makes the autostart bypass structural rather than an exemption list — sound design.

### Nits

1. `engine/cmd/demosrv/main.go:1136` (diff line; `-admintoken` flag help) — "empty flag = DEMOSRV_ADMIN_TOKEN env fallback" contradicts the fail-closed rule three clauses later: an *absent* flag falls back; a supplied-empty `-admintoken=` fatals. Say "unset flag" to match `resolveAdminToken`'s actual contract.
2. `engine/cmd/demosrv/main.go:488` (`handleStart`) — `errStartAborted` from the new stop-pending refusal surfaces to the operator as 502 Bad Gateway with "start aborted (stop requested)". A 409 would be more truthful; cosmetic since the message is clear.
3. `deploy.go:301` — `Authorization: Bearer  tok` (double space, some proxies normalize oddly) fails the compare since `strings.Cut` splits on the first space only. Strictly-conforming clients are unaffected; not worth handling unless a real client hits it.
