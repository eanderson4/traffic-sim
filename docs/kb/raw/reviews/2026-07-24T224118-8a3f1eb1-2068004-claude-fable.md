4. `engine/cmd/demosrv/geojson.go:99` — `isManifest` substring-sniffs `"parts"` in the first 4 KiB; a single-file net whose early bytes happen to contain that token gets `Cache-Control: no-store` on a huge document. A paused-replay attach whose three pulls fail transiently is signal-less indefinitely, since paused replay deliberately no longer rebroadcasts (ADR-0016 §5). Window is narrow (demosrv gates navigation on readiness, so the responder exists) — accepting this as "too early to harden" is a legitimate triage outcome; flagging so it's a recorded choice.
