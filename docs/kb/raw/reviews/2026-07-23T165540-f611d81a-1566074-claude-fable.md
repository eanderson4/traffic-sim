Sandbox denied `go vet`/`go test` here, so this is a static review (worth noting the gate should have run them elsewhere). Findings:

## Findings

**No blockers.** Core loop correctness, determinism discipline, and the `ReplayFromStream` refactor all check out: re-enqueue order is stream order via per-tick slices (no map iteration in stepped paths), wall clock appears only in wrapper pacing per ADR-0005 §4, `indexLogMsgs` is a behavior-preserving extraction (same decode/error paths; only addition is the keyframe-tick list), and the pause/seek serialization through the control channel genuinely guarantees "no tick after /pause returns."

### Should-fix

1. **`engine/natsio/player.go:304` — the `-replay` suffix reservation is one-sided.** `NewPlayer` refuses source ids ending in `-replay`, but `RunLive`/`Registry.Start` still accept them. A run legitimately recorded as `foo-replay` then collides with the replay plane of `foo` on `ts.foo-replay.state.snap` — exactly the collision the refusal is meant to prevent. Enforce the reservation at record time too (`run.go:63` or `validToken` call sites).

2. **Contract note missing (AGENTS.md rule 5 / ADR-0002).** Two contract-adjacent decisions ship with no ADR note staged: (a) reserving the `-replay` run-id suffix in the public subject namespace; (b) a new HTTP control plane (`player.go:589`, `cmd/replay/main.go:111`) — a non-NATS service interface the demo UI will consume, which sits against ADR-0002's "all inter-service communication flows over NATS, no direct RPC." If HTTP-for-demo-tooling is deliberate (defensible — it's an operator console, not a service peer), say so in an ADR-0006 amendment; otherwise `ts.{run}-replay.ctl.*` subjects are the invariant-conforming shape.

3. **`engine/natsio/player.go:459` + `cmd/replay/main.go:142` — unbounded control latency at low speeds.** `checkSpeed` allows any speed > 0; at speed 0.01 with dt 0.1 s the tick-floor sleep is 10 s, during which /pause, /seek, and Ctrl-C shutdown (`Stop(); <-Done()`) all block. Chunk the sleep against `stopping`/`ctrlCh`, or floor the accepted speed. Low severity at demo speeds (0.5–16×) — deferring is a legitimate triage outcome.

### Nits

4. `player.go:378` — the hand-rolled `&Bus{...}` literal bypasses `NewBus`; any future Bus field is silently zero here. A small publish-only constructor next to `NewBus` (bus.go:165) keeps the invariant in one file.
5. `player.go:545` — `seek` clears `done` unconditionally; a seek that clamps to `endTick` re-arms the CAS and re-logs "end of recording" every time.
6. `player.go:600` — /resume's `done.Load()` check races the hold engaging: resume can slip through and leave status `paused=false, done=true`. The hold branch still blocks ticking, so cosmetic only.
7. `player_test.go:920` — `pauseIdx := snaps.len()` after the /pause ack races async NATS delivery: a snapshot published just before pause took effect can arrive after `pauseIdx` is captured and trip the `tick != pausedTick` assert. Tiny in-process window; same pattern at `seekIdx`.

### Question

8. `cmd/replay/main.go:125` — `player.Run()`'s error is discarded (it's currently always nil, so fine today); if `Run` ever grows a real error path, the demo dies silently. Intentional?
