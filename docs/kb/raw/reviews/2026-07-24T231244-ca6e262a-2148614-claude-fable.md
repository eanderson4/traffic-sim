A viz that attaches then fires `requestSig()` at line 875 against a run whose `Bus` (and its sig.req queue subscriber) won't exist for another 100–400 s: `requestMany` fails fast on no-responders, the retry chain at line 372 burns all 3 attempts in milliseconds, and `sigReqRetries` re-arms only on a pull *success* (359) or a reconnect (868). 2. `viz/src/main.ts:386` — `if (res.gap) requestSig()` fires before checking `res.table`, so a chunk that both abandons a dead partial *and* completes a table (`i:1,n:1` after a gap) installs the table and then still pulls the full multi-MB set; likewise a fresh round's chunk 1 arriving after an abandoned round triggers a pull even though that round is actively delivering. Single-flight + static tables make it waste, not corruption, but it adds full-set load precisely under the busy-tab condition. Prefer: install if complete, else pull on gap.
