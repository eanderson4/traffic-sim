### Should-fix

1. **`scripts/osm-stop-nodes.py:553-597` — walks can travel against a oneway and mark non-enterable arms, risking spurious `allway_stop`.** The travel filter (line ~531) is computed only at the stop node from *its* incident ways; it goes inert whenever the ways there disagree (`ow_all` mixed → `travel=None`) or after a split hop onto a differently-tagged way (`is_split` compares class+name, not `oneway` — a street that turns one-way at a split node is a legal hop). A walk then reaching junction J via a oneway's *outbound* end marks an arm that `incident_arms()` counts as 0, so `len(arms) >= total` (line 597) can flip J to `allway_stop` from arms traffic can't use. ADR-0017 §4 covers the explicit-direction case but not this path. Cheap guard: when the walk is on a way with a usable `oneway_tag`, drop the arm if `step` opposes it (mirror of the existing `incident_arms` refusal).

### Nits

2. `scripts/osm-stop-nodes.py:579` — `ways_at.get(end, ()) - seen`: the `()` default would raise `TypeError` (tuple − set) if ever hit. Unreachable today (`end` is always on `cur`), but it's a landmine; use `set()`.
3. `scripts/osm-stop-nodes.py:545` — a tagged stop node referenced by **zero** ways (Overpass pulls them directly) still increments `defaulted` before the way loop no-ops, inflating the reported count.
4. `engine/cmd/netimport/main.go:220` — `-imported` is validated but not normalized: `+00:00` vs `Z` for the same instant yields byte-different provenance → different ADR-0012 content hash. The canned pipeline always passes the Overpass stamp verbatim, so harmless there; a `t.UTC().Format(time.RFC3339)` round-trip would close it for manual use.
5. `scripts/import-city.sh:325` — `REPO_REV` hashes `engine/netimport/netimport.go` by name; a second source file added to that package later silently escapes the importer-identity hash. `engine/netimport/*.go` (excluding `_test`) would be self-maintaining.
6. `scripts/overpass2osm.py:774` — a way with empty `nodes` still emits a `<way>` with no `<nd>`; netconvert tolerates it, but the loud-accounting philosophy elsewhere suggests counting these too.

### Questions

7. `scripts/osm-stop-nodes.py:461-465` — `is_split` returns true on matching `ref` even when `name`s differ (two distinct streets sharing a route ref at a 2-way node get walked through). Likely fine at corners; confirm it was deliberate to check ref independently of name.
8. `scripts/test_overpass2osm.py:1338` — the golden is described as "captured from the pre-change script," but no prior script exists in this repo's history (it lived in the ep-03 repo). Worth one line saying where it came from so the golden's authority is traceable.

### Determinism / contract check (clean)

- No Go map iteration in sampled paths; the only engine behavior change is that `-imported`/`-source-file` replace `time.Now()`/`-in` when given — strictly *more* deterministic, and `import-city.sh:320` refuses the wall-clock fallback.
- Python side: dict/set iteration is order-stable for fixed input; the one `set.pop()` (line 582) operates on a ≤1-element set (split ⇒ exactly 2 ways, current way ∈ `seen`), so output is input-determined. `render()` sorts node ids.
- `provenance.imported` semantic widening is a documented contract change with ADR-0017, contract doc, and the `netfile.go` comment all aligned; no wire schema affected.
