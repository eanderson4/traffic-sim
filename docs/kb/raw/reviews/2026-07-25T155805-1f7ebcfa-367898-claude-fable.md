## Findings

**Blockers:** none.

**Should-fix:** none. The two shutdown races I chased hardest both close cleanly:
- A start that passes both `closed` checks before `shutdownFinal` stores the latch is always covered by the abort stamp — with Go's SC atomics, `startGen.Add` happens before the start's second `closed.Load`, which precedes `closed.Store(true)`, which precedes `shutdownFinal`'s `startGen.Load()`, so `abortGen` always includes the in-flight generation (`supervisor.go:347-354`, `deploy.go` retry loop). The reaper's new `s.active = nil` clear can't double-fire against `stopLocked` because `stopLocked` nils `active` before waiting on `done`.
- The `hs.Serve` error path (main.go, patch line 1131) calls `shutdownFinal()` but never closes `srv.shutdown` — benign, since `log.Fatalf` exits the process immediately and the latch already blocks new spawns.
- `waitIdentity`/`wsDialURL` correctly keep probing the *local* listen address when `-wspublic` is set — the probe must hit the pod's listener, not the LB. Verified no other advertisement path bypasses the two overridden functions.

**Nits:**
- `deploy.go:264` — `strings.CutPrefix(..., "Bearer ")` is case-sensitive; RFC 9110 auth schemes are case-insensitive (`bearer x` from some proxies/clients will 401). Every mainstream client sends `Bearer`, so cosmetic here.
- `deploy_test.go:853-895` — `TestResolveAdminToken` hand-rolls env save/restore; `t.Setenv` does this and additionally guards against a future `t.Parallel()` in the package (other tests here share package-level ws vars via `pinWSVars`, same hazard class).
- main.go patch line 1135 — `sup.shutdownFinal()` before `log.Fatalf` skips the deferred `os.RemoveAll(binDir)`; pre-existing on every other `Fatalf`, just noting it's not made worse.

**Questions:**
- `-wspublic` set with no admin token resolves to a fully open mutating API on the exact deployment shape the flag exists for. ADR-0020 treats the (bigger) unauthenticated ws plane as go-live-gating, so this is consistent — but a one-line startup warning (`-wspublic set, admin gate OFF`) would be cheap insurance against a manifest that drops the Secret. Acceptable now (7 routes, tested), worth remembering when the surface grows.
