## Findings

**should-fix — `scripts/show/build-quiz.sh:76`: `set -e` aborts the build in the intended fallback path.**
The script runs under `set -euo pipefail` (line 13). In the else branch, `[ -f "$DIAG/chi-loop-urban__setup.png" ] && echo ...` is the branch's final statement; when `CHI_METRICS` is unset **and** the PNG is absent, the AND-list returns 1 and `set -e` kills the script there — `mkquiz.py` never runs, exit 1, and the last output is the informational "leaving the Chicago setup slide as found." The designed outcome (text-only Chicago card) never happens. Masked today only because the PNG is committed. Use `if [ -f ... ]; then echo ...; fi` or append `|| true`.

**should-fix — `docs/show/img/chi-congestion-fw35.png` staged without its provenance sidecar.**
`mkcongestionmap.py` unconditionally writes `<out>.png.json` (diff line 6012), and both the script's own comment ("a stale PNG under the right filename looks exactly like a fresh one") and article §8 argue a congestion PNG without provenance is "a drawing again." The article's illustrating PNG ships exactly that way — no `chi-congestion-fw35.png.json` exists even in the working tree. Stage/regenerate the sidecar.

**should-fix — committed sidecar's provenance is an ephemeral scratch path (`docs/show/diag/chi-loop-urban__setup.png.json`).**
`metrics` is `/tmp/claude-1000/.../scratchpad/base18k.metrics.json` — a session scratch dir that no longer exists — plus a machine-absolute network path (leaks local username into the repo). As committed, the sidecar cannot answer its stated purpose ("say WHICH run"); `metrics_bytes` is the only weak identity. The metrics doc carries no run identity to copy (`engine/metricsjson.go:18-25` — no seed/scenario/hash), so have build-quiz/mkcongestionmap record scenario dir, run id, seed, ticks (build-quiz's caller knows them), or at minimum repo-relative paths.

**nit — article §8 contradicts its own table.** "the table said the expressways ran at 36-41 km/h" and later "a headline of 36-41 km/h," but the table two paragraphs down reads 31.7–46.4 (LSD 31.7, Kennedy 46.4). If 36-41 quotes the earlier shipped table from a different run, say so explicitly — as written the range excludes two of the five corridors shown.

Harmless while runs emit one set, but the show's corridor tables came from the unguarded script; worth one KB line or the same guard there.
