## Review — city-import pipeline (staged diff)

Scope: new Python import/render scripts + tests, `import-city.sh`, two additive `netimport` flags, contract-doc additions, ADR-0017. No NATS subject or payload changes; the netimport flags are additive CLI provenance knobs, and ADR-0017 covers the import trade-offs — contract discipline is satisfied.

### Should-fix

1. **`scripts/import-city.sh:286` — `$REPO_REV` in `-source` re-introduces the hash instability this same script refuses over.** `provenance.source` rides in the network JSON, which the scenario content hash canonicalizes whole (`engine/scenario/scenario.go:217`, provenance included — same channel the new `main.go:26,28` flag docs warn about). The script hard-fails on a missing extract timestamp because "identical inputs hash differently" (line 280), then stamps `import-city.sh@$(git rev-parse HEAD)` — so re-importing identical inputs at any later commit moves the content hash anyway, and HEAD says nothing about a dirty working tree, so it isn't even reliable provenance. Same applies to `$NC_VER`/`$PASSES` to a lesser (more defensible) degree. Either move REPO_REV into `import-report.json` (unhashed) and keep `-source` checkout-independent, or record the "source string is versioned provenance, re-imports are new identities" stance explicitly in ADR-0017.

### Nits

2. `scripts/osm-stop-nodes.py:494` — oneway inference compares whole sets: `{"yes","true"}` (mixed spellings across ways at the node, or a split) defeats inference and silently defaults forward. `if ow <= {"yes","true","1"} and ow` would cover it; fine to leave.
3. `scripts/osm-stop-nodes.py:542` — allway promotion counts arms as `(way, sign)` pairs, but a walk along a oneway that only *exits* the junction records an arm that `incident_arms` counts as 0. A mapper-error stop (direction against the oneway, walked-as-tagged per docstring) can then satisfy `len(arms) >= total` and promote a junction to `allway_stop` while a real approach carries no stop. Consistent with the stated mapper-error policy; noting so the asymmetry is known.
4. `scripts/osm-stop-nodes.py:500` — `way_nodes[wid].index(nid)` walks from the *first* occurrence on a self-intersecting way. Vanishingly rare; fine.
5. `scripts/import-city.sh:236` — hardcoded `python3.12` venv path; matches the existing contract-doc recipe, breaks on the next Python bump.

### Checked and clean

- **Determinism:** walks iterate `sorted(ways_at[...])`, sets are membership/commutative-sum only, output sorted by node id; `overpass2osm` emits in insertion order — all deterministic for a given input. `time.time()`/wall clock appear only in `render-city.py` logging (offline render, not sim-affecting). The `netimport -imported` validation and the script's refusal of a missing `timestamp_osm_base` are correct RFC3339-wise (Overpass emits `...T00:00:00Z` form).
- **Walk control flow** (`osm-stop-nodes.py:507-537`): inner-while/`else`/hop/`continue` structure is correct; per-step state reset prevents the `direction=both` leak the test at `test_osm_stop_nodes.py` regression-covers; hop `nxt.pop()` is deterministic (a split has exactly 2 ways, ≥1 in `seen`); `ways_at.get(end, ()) - seen` can't hit the tuple default since `end` is always a way ref.
- **Signal protection** both at the stop node itself and along the walk — matches the "never downgrade a light" invariant, tests cover both.
- **`overpass2osm.py`:** loud hard-fail on unresolvable way refs, tag merge on duplicate node elements, correct attribute escaping (incl. quotes), golden test pins old-shape byte-for-byte output.
- **`import-city.sh` empty-override path:** `osm-stop-nodes.py` writes a zero-byte file for an empty mapping and `[ -s ]` correctly selects single-pass; generated `scenario.yaml` keys and `types: [car, truck]` match the `Manifest`/`Spawner` schema and shipped scenarios.
- **`render-city.py`** field names (`internal`, `row`, `tl`, `speedLimit`, `shape`) all match `engine/netfile.go`; `row` is genuinely internal-lane-only, so keying stop markers off internal lanes is right.

One should-fix (or one ADR sentence to make it deliberate); nothing blocking.
