  2. **`engine/natsio/verb.go` `decodeLoggedVerbAny` (the `signal_set` branch, ~line 205) — `hold_ticks` escapes the presence check the ADR's own round-5 discipline mandates.** `signal_idx`/`phase` are presence-checked because 0 is legitimate; for `hold_ticks`, 0 is *never* legitimate on the record (the encoder writes the effective hold, which is ≥ 1 always — default is `p.cycle` ≥ 1, clamp is `max(1, …)`).
