- **blocker** — `docs/kb/decisions/ADR-0020-demosrv-public-deployment.md:80`: `-wspublic` intentionally exposes an unauthenticated NATS/JetStream endpoint where arbitrary clients can publish controller intents and JetStream API requests, contradicting ADR-0006’s observer-read-only contract. The HTTP bearer gate does not protect this plane. Public deployment must be blocked until broker authentication/permissions exist.
- **should-fix** — `engine/cmd/demosrv/main.go:82`: the “fragment-free” validation accepts URLs ending in an empty fragment such as `wss://traffic.example/#`, because `url.Parse` yields `u.Fragment == ""`. The raw value is then advertised verbatim, and browsers reject it as a WebSocket URL. Detect the presence of `#`, not only a nonempty parsed fragment.
