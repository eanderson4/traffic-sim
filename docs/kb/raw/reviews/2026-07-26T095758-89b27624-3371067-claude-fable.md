## Blocker

1. **Data race in the demand director** — `engine/natsio/demand/director.go:189,195`: `d.Claims += …` / `d.Unclaimed += …` increment in NATS callback goroutines without `d.mu`, while `onSnapshot` (:266) and `Close` (:235) read them under the lock. Genuine Go-memory-model race; any `-race` run with claim traffic flags it. Four-line fix.

## Should-fix

2. **Failed cursor reset → silent uncontrolled playback** — `engine/natsio/logcursor.go:254-256` + `player.go:504-506`: if `reset()`'s inner `open()` fails mid-seek, the cursor is closed but `curSeq`/`lastSeq` keep old values; when `curSeq == lastSeq` every later `nextMsg` returns `nil, nil` and the player steps empty, CRC-unverified ticks to `endTick` with no divergence report — contradicting ADR-0024 §5's own "read faults propagate, never silent truncation" promise.
3. **`send()` drops arrivals on publish failure** — `demand/director.go:306-315`: on `PublishRequest` error it now logs and advances `fs.next(...)`; the old code retried the same arrival next snapshot. A reconnect window silently loses a burst of demand while still counting it in `Sent`.
4. **ADR-0025's content-hash claim is false as implemented** — `engine/cmd/serve/main.go:190` mutates `spec.Params.SafetyDecel` after `sc.Hash()`; the scenario grammar has no safety-decel key, so gated and ungated runs share (scenarioHash, seed) run identity with different physics. Replay is safe (`RunMeta.Spec` records Params — verified), but either the ADR text or the hash needs to change.
5. **Stale frame emitted after seek/pause/close** — `viz/src/baked.ts:637-680`: `emit()` never re-checks `gen`/`closed`/`paused` after the stall-barrier `await` (:658); a stalled step resumed after a seek-back delivers its later tick, and `SnapshotBuffer.push` then drops every legit frame ≤ that tick (verified: no re-check exists before `onFrame` at :680).
6. **Unbounded decoded-chunk caches** — `viz/src/baked.ts:403-404`: `frameCache`/`laneCache` only evict failures; a long city replay grows browser memory without bound — the exact failure ADR-0024 just bounded on the Go side.
7. **mkod.py demand YAML not byte-reproducible** — `scripts/chicago/mkod.py:297-298`: `through_for` iterates a set, so float blend order is hash-randomized; a weight on a `%.4f` boundary can flip between runs. Iterate the already-sorted `fw_exits` (:272).
