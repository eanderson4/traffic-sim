## Review — ADR-0020 demosrv public deployment

Verified: package compiles, `go vet` clean, full `demosrv` test suite passes. All ws-advertisement call sites (`main.go:121`, `main.go:456`, `main.go:508`, `replay.go:135`) route through `wsClientURL`/`advertisedWsURL`, both of which honor the `-wspublic` override; the probe-side `wsDialURL` (`supervisor.go:487`) correctly keeps dialing the pod-local listen address. The `shutdownFinal` closed-latch / abort-generation protocol (`supervisor.go:346-360`, `supervisor.go:225-255`) is sound under Go's SC atomics: a start that passes the second `closed` check under `mu` did so before `closed.Store(true)`, which precedes the `abortGen` stamp, which therefore reads a `startGen` that covers that start's generation — no start can both slip the latch and dodge the abort, and `waitReady`'s abort path kills the just-spawned child before returning. The mutating-route set behind `adminGate` is exhaustive: every non-GET route in `routes()` is wrapped; all GETs are read-only against demosrv state (the `/net` cache-fill caveat is ADR-documented). No blockers.

**Blockers** — none.

**Should-fix** — none. (Determinism: no sim-path code is touched; the backoff/`time.After` use is control-plane orchestration, outside ADR-0005's scope. Contract: no NATS subject or payload changes; the new HTTP 401 behavior and the changed `ws` advertisement values are exactly what ADR-0020 records.)

**Nits**
1. `engine/cmd/demosrv/deploy.go:334` — the `errStartAborted` log says "start aborted by a stop request" and "NOT retrying" as if an operator stopped it, but process shutdown reaching an in-flight start via `shutdownFinal`'s abort stamp takes this same branch (the `errSupervisorClosed` check only catches starts that hadn't yet passed the latch). The log lies about the cause during shutdown; cosmetic, since the return is correct either way.
2. `engine/cmd/demosrv/deploy_test.go:888-895` — `TestResolveAdminToken` hand-rolls save/restore with `os.LookupEnv`/`t.Cleanup`; `t.Setenv` does this and additionally guards against `t.Parallel` misuse.
3. `engine/cmd/demosrv/deploy.go:268` — `CutPrefix(..., "Bearer ")` makes the auth scheme case-sensitive; RFC 7235 schemes are case-insensitive. Acceptable for an operator-controlled client set, but a `bearer`-sending client gets an unexplained 401.

**Questions**
1. `docs/kb/INDEX.md:27` — the footer gains an "ADR-0020 ratified" line, and the checklist above newly marks ADR-0019 `[x]`, but no ADR-0019 ratified footer line is added. Intentional?
2. `engine/cmd/demosrv/main.go` route table — `GET /net/{file}` triggers on-demand server-side GeoJSON cache generation (CPU + disk on the pod), not just egress. ADR-0020's deferral paragraph frames the exposure as "egress/abuse … LB/CDN rate limits"; worth confirming the deferral is understood to cover the compute-side cost too (it's bounded — registry ids only, cached after first build — so likely fine).

The ADR itself is unusually honest about the real go-live gap (the unauthenticated, publish-capable engine ws plane that `-wspublic` exists to expose) and correctly scopes it as a deployment precondition rather than this commit's problem; the startup warning at `main.go:149-155` keeps that from being forgotten.
