## Question

4. **Budget widens the failover re-draw window (accepted risk?).** Pre-change, a vehicle's exit resolved at its first observation; now it can sit unresolved for `⌈fleet/budget⌉` ticks. If the replica dies in that window, the re-claimer captures `wantLane` at *its* first observation — the vehicle has moved, so it may draw a different exit than the dead replica would have, stretching ADR-0008 §6's "behaviorally invisible" failover. destinations.go:26–30 already accepts this residual and engine-side route persistence covers the resolved case; flagging only because the window is now materially wider. Fine to defer with a note.
