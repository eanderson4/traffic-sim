- **blocker** `engine/keyframe.go:311` — Restore rejects v6 adaptive state into a static spec, but accepts pre-v6 static state into the newly default-adaptive spec. Thus an existing `-state-in` file restored from an unchanged manifest silently switches routing policy and cannot continue bit-exactly. Since adaptive engines always write v6, a pre-v6 keyframe conclusively indicates static routing; require an explicit migration override or fingerprint resolved params in the sidecar.
- **should-fix** `engine/scenario/scenario.go:57` — Changing `AdaptiveRouting` from `bool` to `*bool` changes canonical YAML—and therefore hashes—for existing manifests explicitly containing `adaptive_routing: false`, while retaining the `scenario-hash/v1` domain. This contradicts the adjacent invariant that canonicalization changes require a protocol bump; ADR-0036 acknowledges the hash shift but does not amend ADR-0012 or version the hash protocol.
