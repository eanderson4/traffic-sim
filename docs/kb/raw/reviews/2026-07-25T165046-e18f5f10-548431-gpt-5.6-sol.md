- **blocker** `engine/cmd/demosrv/supervisor.go:285` — Appending a random nonce changes every live demo’s NATS namespace from the registry-declared `ts.{run}.>` to `ts.{run}-{nonce}.>`. External controllers using the configured run ID will no longer attach, and this subject/identity contract change is absent from ADR-0020 and has no migration note. Document/approve the contract change and provide consumers the resolved run ID, or retain the stable namespace.
- **should-fix** `engine/cmd/demosrv/deploy.go:160` — Autostart snapshots `stopEpoch` inside its goroutine. A `POST /api/demo/stop` can complete after the listener binds but before this goroutine runs; autostart then snapshots the incremented epoch and starts anyway, undoing the operator’s stop. Capture the epoch synchronously before launching autostart, or add an explicit autostart-cancel latch.
