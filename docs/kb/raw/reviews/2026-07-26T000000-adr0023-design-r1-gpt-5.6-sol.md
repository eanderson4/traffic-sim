**Blocker**
- **TSRB chunks are not decodable.** A chunk concatenates 120 variable-cardinality frames, but the frame header has neither `vehicle_count` nor `frame_bytes`; the next frame boundary cannot be determined safely. Add a count/length field or a chunk-level offset table. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:133`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:169`
- **Concatenated TSSG lacks framing.** `signals.tssg` stores multiple variable-length frames but the index supplies only a chunk count; the existing decoder rejects trailing bytes. Store separate objects, byte lengths, or length-prefix each frame. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:118`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:222`, `viz/src/tssg.ts:135`
- **The PMTiles path is not drop-in as written.** Vector layers require `"source-layer": "lanes"`, and every `setFeatureState`/`removeFeatureState` identifier must include `sourceLayer`; current layers and calls omit both. `promoteId` does not remove that requirement. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:266`, `viz/src/main.ts:582`, `viz/src/main.ts:1002`, `viz/src/main.ts:1035` 
- **The bake key is not content-addressed.** Its inputs omit seed, recorded stream contents/end sequence, end tick, bake parameters, and tool versions. Scenario hash explicitly excludes seed and ticks, while run identity is `(content-hash, seed)`. This can reuse a key for different output. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:299`, `docs/kb/decisions/ADR-0012-scenario-format.md:113`, `docs/kb/decisions/ADR-0012-scenario-format.md:215`
- **Low-zoom bandwidth math contradicts the table.** `80–150 MB / 15 min` is **5.3–10 MB/min**, not `0.25 MB/min`; raw TSRL at 50k pairs is ~30 MB/min. Likewise, 50k-vehicle TSSF at 10 Hz for 15 minutes is ~10.8 GB, not 2.16 GB. The public-view fetch story depends on correcting this. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:329`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:331`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:337`, `engine/natsio/frame.go:39`

**Should-Fix**
- Chunk boundaries conflict: 120 frames cannot be inclusive ticks `0..600` at stride 5—that is 121 frames. A run including ticks 0 and 9000 has 1801 frames, not 1800. Specify half-open intervals plus `frameCount`. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:169`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:227`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:233`
- Existing interpolation is not smooth at 2 Hz with the default 250 ms buffer: the source interval is 500 ms, so the buffer repeatedly starves and holds. Baked mode needs cadence-aware buffering or tick-time scheduling. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:154`, `viz/src/config.ts:37`, `viz/src/snapshots.ts:53`, `viz/src/snapshots.ts:103`
- Define TSRL lane-to-region ownership. A lane may cross regions and contain vehicles in several regions; duplicate ratios need merge rules, while single-owner assignment can omit visible lanes. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:200`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:204`
- Bake the derived `edgeB` property. The current client computes it from the complete network; PMTiles mode lacks that geometry and otherwise renders every lane as a full road casing. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:95`, `viz/src/main.ts:233`, `viz/src/main.ts:248`, `viz/src/main.ts:552`

- Pin tippecanoe version and complete flags; prohibit feature dropping/coalescing that destroys per-lane identity. Direct PMTiles output and per-feature minzoom are feasible. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:91`, `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:96` 
- `id u32` narrows the engine’s `uint64` identity without a format invariant. Either retain u64 or require the bake to abort when `nextID-1 > MaxUint32`. `docs/kb/decisions/ADR-0023-baked-replay-pipeline.md:148`, `engine/vehicle.go:48`, `engine/engine.go:75`
