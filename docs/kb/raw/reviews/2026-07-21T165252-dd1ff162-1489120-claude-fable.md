**Blockers:** none.

**Should-fix**

1. **`engine/director.go:92-101` + `engine/replay.go:66` — new dedup rejection is fatal in replay of any pre-change recording containing simultaneously-live duplicate RequestIDs.** `Replay` and `natsio.ReplayFromStream` (replay.go:160) treat an `EnqueueSpawn` error as fatal. A recording made before this commit whose `SpawnLog` holds two live-at-once directives with equal RequestIDs — including the empty string, which `EnqueueSpawn` still accepts as a valid ID — will now fail to replay at all. The contract layer's first-seen dedup means wire-produced recordings can't contain such pairs, so this is likely unreachable in practice, but the commit message or KB should record that any local-harness recording with duplicate live IDs is retroactively unreplayable. (If empty RequestID is not meant to be legal, rejecting it explicitly would be cleaner than letting two `""` directives collide as "duplicates".)

**Nits**

2. **`engine/metrics_test.go` (TestKernelEmptyInterval, `// [1,101), [101,201), partial [201,251)`)** — stale comment: the stamped convention is `[0,100), [100,200), [200,250)`, exactly as TestKernelPartialFinalInterval asserts. The test only checks the count, so nothing fails, but the comment contradicts the interval-stamping pin the rest of the file teaches.

3. **`engine/metrics.go` `accountShares` D==0 path** — when no share is positive, the full `totalT`/`tickLoss` books to the *last* share even in the single-share despawn case where that share is a negative overshoot refund and `prev.v == 0` (so `t` stays `dt`). This mildly contradicts the "refund carries distance only" doc. The booking is defensible (the vehicle did exist that tick) and the state is barely reachable (stopped, overshoot-parked, then despawns), so document-or-ignore.

4. **`engine/metrics.go` `Totals()` mid-run** — `ActiveAtHorizon` reads 0 until Finalize while `MeanTimeLossS` already uses the live `len(k.last)` denominator; a polling consumer sees a half-live/half-horizon struct. The ADR addendum flags mid-run `DroppedCrossings` as provisional; extending that sentence to `ActiveAtHorizon` would cost one clause.
