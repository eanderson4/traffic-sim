**Findings**

**Should-fix**

1. `engine/cmd/serve/main.go:155` — The `-pace 0` guard only checks `*withDriver`, but the demand director (attached at main.go:309 when `scen.Demands` is non-empty) is the same kind of NATS replica riding the snapshot rhythm (`demand/director.go:179`). An unpaced loop outruns it identically: verbs land late or after the horizon, and a `-store` durable recording silently ships with the demand realization missing — the exact artifact `-store` exists to preserve. `scen` is already loaded at this point; gate on `(*withDriver || (scen != nil && len(scen.Demands) > 0))`, or at least say so in the flag help (it currently only names the driver).

**Nit**

2. `engine/cmd/serve/main.go:358-362` — A huge finite pace (e.g. `-pace 1e12`, dt=0.1) truncates `time.Duration(v)` to 0: silently unpaced with `-driver=false`, and with the driver it exits via the pace-0 branch with a message claiming the user passed `-pace 0`, which they didn't. Cheap fix: after conversion, `pace > 0 && dur == 0` → its own usage error.

3. `engine/cmd/serve/main.go:360` — The error message says "underflows the tick floor" but this branch fires when the floor *overflows* (tiny pace → huge floor). Also `v > math.MaxInt64` should be `>=`: `math.MaxInt64` as float64 is 2⁶³, so `v == 2⁶³` passes the check and the conversion is out of range (on amd64 yields a negative Duration → silently unpaced). Astronomically narrow, but the fix is one character.

**Question**

4. `viz/src/config.ts:365` / `main.go:327` — `?dt=` trusts the URL; a hand-typed URL against a non-0.1-dt scenario silently scales every speed and the congestion overlay by the ratio, with nothing on screen to notice. The run registry `{run}/meta` (ADR-0006 §1) already carries the run spec — is reading dt from there over the WS plane on the roadmap, with `?dt=` as the interim? Fine for the demo since the serve printout embeds the right value; just confirming the URL param isn't becoming the durable interface.

5. `engine/cmd/serve/main.go:378` — `checkFreshRecording` passes an *existing empty* stream and lets the recorder adopt it, config unseen (the test even relies on adoption of a hand-made stream). Only reachable by hand-crafting a stream in the store, so fine today; noting it since "one run per stream" is load-bearing for replay.
