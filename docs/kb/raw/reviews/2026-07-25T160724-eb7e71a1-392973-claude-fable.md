**Should-fix**

1. `engine/cmd/demosrv/deploy.go:317-343` — an operator's authed `POST /api/demo/stop` that lands while an autostart attempt is mid-startup gets overridden. `stop()` stamps `abortGen`, the in-flight `startIfIdle` fails with the generic `"did not become ready: start aborted (stop requested)"` (supervisor.go:486/521), and `autostartDemo` treats that as transient — the next retry finds the supervisor idle and restarts the demo the operator just stopped. The loop is careful never to *replace* an operator's run but does un-do an operator's stop. The abort error is a plain `fmt.Errorf`, so autostart can't distinguish it; a sentinel (like `errAlreadyActive`/`errSupervisorClosed`) treated as terminal closes it. Window is small (boot-time, ≤4 attempts) — defer with a note if you'd rather not respin.
