## Findings

**Blockers** — none.

**Should-fix**

1. **Contract ships ahead of its implementation.** `contracts/asyncapi.yaml:137` (new `stateSigReq` channel) and the `sig_chunk` header, plus ADR-0016 flipped to ACCEPTED, describe engine behavior (`SigChunkMax` chunking, cached-slice republish, 4 MiB `MaxPayload`, loud size logging) that exists only as **unstaged** working-tree edits to `engine/natsio/*` and `engine/cmd/serve/main.go` — nothing at HEAD or in this staged diff serves `ts.{run}.state.sig.req`. If contract-first ordering is deliberate, say so in the commit message (a one-line "impl lands next commit" migration note keeps the sacred-contract rule honest); otherwise stage them together. As written, ADR-0016's decisions read as shipped fact.

2. **ADR-0016 dropped the draft's `sig_gen` generation header and replaced it with nothing** (`docs/kb/decisions/ADR-0016-tssg-chunking.md` decision 4; `contracts/asyncapi.yaml` `SigChunkHeaders` carries only `sig_chunk`). The accumulator's gap/regression/count-change resets cannot detect the aligned-drop case: client holds G1 chunks `1..i-1`, drops G1 `i..n` and G2 `1..i-1`, receives G2 `i..n` — indices are consecutive, n unchanged, and a mixed-generation table installs silently. Harmless today only because the table is immutable per run (chunks are byte-identical across rounds modulo the patched tick). The prior PROPOSED draft had `sig_gen` for exactly this; the accepted ADR should record *why* it was removed and pin the constraint ("safe only while tables are immutable; mutable tables (ADR-0011 D1) must reintroduce a generation id") rather than staying silent — a future reader of decision 4 ("tick is never generation identity") will ask what *is* the identity.

**Nits**

3. `scripts/osm-stop-nodes.py:195` — `way_nodes[wid].index(nid)` takes the first occurrence; a stop node appearing twice in a self-touching way walks the wrong segment. Rare, self-limited.
4. `scripts/osm-stop-nodes.py:137` — `incident_arms`: a way with the junction at one end *and* interior (P-shape) counts 1 arm, not 3; undercounting `total` can promote `priority_stop` to `allway_stop`. Rare geometry.
5. `scripts/osm-stop-nodes.py:180` — explicit `direction` fighting the oneway flow filters `steps` to empty and drops the stop **silently**, while direction-defaulted stops are counted and reported. ADR-0017 §4 documents the drop; a count in the same stderr line would keep it observable.
6. `scripts/import-city.sh:69` — `REPO_REV` hashes five files but the comment claims "content hash of the whole import pipeline"; `netimport` also depends on `engine/netfile.go` (and the rest of the engine package), so importer changes there don't move the stamp. Harmless today (the network content hash still moves), but the comment overclaims.
7. `scripts/render-city.py:187` — the `--label` lane count uses `len(lanes)` including internal lanes, inflating the headline figure relative to what's drawn.
8. `scripts/overpass2osm.py:99` — a way element missing its `nodes` key emits an empty `<way>`; the loud missing-ref check can't catch it since there are no refs to check.

**Questions**

9. `contracts/asyncapi.yaml` `stateSig` chunking note says "recovery is the request/reply channel … not waiting out a round" while ADR-0016 decision 2 retains the 20-tick republication. Both can be true (push cadence stays, pull is the *recovery* path) — confirm the surviving prose elsewhere in the channel description doesn't still present the 20-tick round as the resync mechanism.

Determinism check: clean. The import scripts are deterministic given the same input (sorted walks and rendered output in `osm-stop-nodes.py`; the one `set.pop()` at the split hop is provably ≤1 element; insertion-ordered emission in `overpass2osm.py`), wall clock appears only in the netimport *fallback* that `import-city.sh` explicitly refuses, and `-imported` is canonicalized to UTC before hashing. Nothing here touches the tick loop or RNG. ADR coverage for the contract change (ADR-0016) and the import deviations (ADR-0017, with the ADR-0009 supersession note) is in place.
