## Findings

**Blockers** — none. Chunk ordering rests on invariants that genuinely hold (single goroutine, sequential async publishes on one connection, predicted-seq OCC per message, per-tick batch await); `findKeyframe` reassembly is consistent-and-fail-loud; the escape is dead wall-clock time and the new replay-CRC test pins that; the contract changes (new `kf_chunk` header, escape-resume semantics) are documented in `contracts/asyncapi.yaml`, ADR-0015, and the ADR-0008 §6 amendment — contract discipline satisfied.

**Should-fix**

1. `engine/natsio/replay.go:283,299` — retention can brick all seeks, not just the pruned one. With `RecorderConfig.MaxAge > 0`, JetStream expires messages individually; a chunk group straddling the expiry boundary leaves an orphan tail (chunk 1 gone, 2..n present). `findKeyframe` scans the whole keyframe subject from seq 0 and errors on that orphan (`want == 0` branch) — so a stale partial group at the stream head fails every seek, including to intact later keyframes. Relatedly, `replay.go:211` (`indexLogMsgs`) counts a keyframe whenever `i == n` with no group validation, so the index accepts the same stream `findKeyframe` rejects. Per the triage bar this is defer-able (MaxAge is 0 for tests/local runs) — but record it: "MaxAge + chunked keyframes = replay hazard" belongs in the ADR-0015 consequences or the commit message.

**Nits**

2. `contracts/asyncapi.yaml:955` — pattern `^\d+/\d+$` admits `0/3` and `4/3`; the parser (`replay.go` `parseChunkHeader`) enforces `1 ≤ i ≤ n`. Tighten or leave.
3. `engine/natsio/recorder.go:1671` (`headerKeyframeChunk = "kf_chunk"`) — nats.go canonicalizes header keys, so the wire key is `Kf_chunk`. Same pre-existing situation as `tick`/`schema_version`; only matters to non-Go consumers matching case-sensitively. Doc-level at most.
4. ADR-0015 item 2's stated fail-loud mechanism is imprecise: chunk 1 *does* start with the TSKF magic; old readers actually fail via the codec's short-read error (`engine/keyframe.go:316`) and the duplicate-tick index check. Conclusion holds; the rationale sentence doesn't.
5. `analysis/networks/netstats/main.go:290` — `edgeLen[l.Edge] = l.Length` is last-lane-wins; lanes of one edge differ in length on curves, mildly biasing block-length stats. `main.go:349-357` — `SignalShare`'s numerator junctions aren't constrained to the denominator's internal-lane-derived junction set, so >100% is theoretically possible. `main.go:392` — `sort.Slice` is unstable; LaneKM ties could reorder the table across runs. All analysis-tool-grade; fine as-is.
6. `engine/natsio/keyframe_chunk_test.go` seek-anchor assertion is vacuous if the keyframe group happens to be the last messages on the stream (`len(next) > 0` guard); harmless here since CRC/verb messages follow.
