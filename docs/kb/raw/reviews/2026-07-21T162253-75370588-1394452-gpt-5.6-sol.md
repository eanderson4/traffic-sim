- **blocker** `engine/metrics.go:1084` — “Shortest chain” selection is actually shortest hop-count, with ties retaining successor order (`engine/metrics.go:1012`). Equal-hop paths with different lengths can therefore book the longer path, corrupting VMT, trip distance, and lane metrics.
- **blocker** `engine/metrics.go:1087` — Equal-length parallel paths are treated as unambiguous, although their intermediate-lane attribution differs. This silently publishes incorrect per-lane intervals and contradicts the ADR’s “ambiguous-branch cases … loud, never silent” rule. The same defect exists for live crossings at `engine/metrics.go:975`.
- **blocker** `engine/metrics.go:424` — Invisible vehicles are detected only when a later, higher ID becomes observable. A trailing same-tick spawn/despawn—or a run where every vehicle is invisible—leaves no gap and remains silent, contradicting the addendum’s loudness guarantee. `TestKernelInvisibleGap` deliberately adds another origin to hide this case.
- **should-fix** `engine/metrics.go:1013` — `len(chains) == capN` does not prove enumeration was truncated. Exactly three fully enumerated paths are falsely reported as truncated, inflating `DroppedCrossings`.
- **should-fix** `engine/metrics.go:644` — Director demand state is keyed solely by `RequestID`; duplicate or empty IDs collapse. Wait accrues per queue entry, but `DeniedServed` can count several completed/expired requests as one. The public engine enqueue path does not enforce uniqueness, so the normative per-request totals are inconsistent.
