**Should-fix**

1. **Autostart retry can kill a manually started run.** `deploy.go:204-219` — `sup.start` unconditionally replaces the active child (`stopLocked` at `supervisor.go:192`). If an autostart attempt fails and an operator starts a demo through the authed route during the backoff window (which can span minutes: up to three 60 s readiness timeouts + 2/4/8 s sleeps), the next retry silently kills that run and spawns its own. Cheap guard: before each retry, bail if `s.sup.status()` reports an active run — someone else won, autostart's job is done.

2. **Admin token intake is argv-only.** `main.go:659` — `-admintoken` puts the secret in `/proc/*/cmdline` and forces it into the pod spec's `args` (visible to anyone with `kubectl describe`). K8s convention is a Secret via env/file. The deploy manifests are out of repo per the ADR, but the intake mechanism is in-repo; an env fallback (`DEMOSRV_ADMIN_TOKEN` when the flag is empty) is a few lines.
