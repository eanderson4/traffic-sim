## Review — staged diff (TSSG chunking + sig.req pull, chunked GeoJSON, run-id identity, themes/stop signs)

### Blockers

None found. Contract discipline is satisfied (ADR-0016/0018 ratified in this change, asyncapi bumped to 2.3.0, new subject + `sig_chunk` header documented); no Go map iteration, wall-clock, or float-accumulation entered any deterministic path (chunk packing is a pure function of file-ordered slices; `crypto/rand` nonce is operational identity, not a sim input).

### Should-fix

1. **`supervisor.start` now holds `s.mu` for up to ~660 s, blocking `/api/status` and the replay proxy for the whole big-city spawn** — `engine/cmd/demosrv/supervisor.go:160` (start takes mu, defers unlock) + `supervisor.go:190` (waitReady→waitIdentity inside the lock, `identityTimeout = 660s` at supervisor.go:63). `status()` (supervisor.go:258) and `withActiveReplay` also take `s.mu`. Before this change the worst-case hold was ~10 s; now a routine la-lean spawn (~400 s world build) hangs every 3-second menu status poll and piles up HTTP goroutines until start returns. Doesn't corrupt anything, but it's a real availability regression on the normal path. Snapshot status fields outside the long wait (or a separate state mutex).

2. **Paused replay can end up permanently signal-less: the pull budget (3) has no fallback while paused** — `viz/src/main.ts` `requestSig` (`sigReqRetries >= 3` guard) combined with `engine/natsio/player.go:404` (republishPaused deliberately no longer broadcasts the table, ADR-0016 §5). While paused, the request/reply path is the *only* source of the table; if the 3 pulls fail (the busy-tab drop scenario this feature targets), nothing re-arms until resume or a full reconnect — the exact "no signals in this city" symptom the change fights. Consider re-arming the retry budget on a slow timer (e.g. 60 s) when no table is installed, not only on reconnect.

3. **`stop()`/`start()` interleave can spuriously abort a legitimate start** — `engine/cmd/demosrv/supervisor.go:229` sets `stopRequested` before taking `s.mu`; a concurrent `start()` that wins the lock first spawns a child, then its `waitPort`/`waitIdentity` sees the flag and aborts with "start aborted (stop requested)", killing the fresh child; the queued `stop()` then clears the flag over an idle supervisor. Client sees a 502 on a valid start. Low probability (needs stop and start racing from separate HTTP requests), but the flag should probably be generation-scoped (owned by the activeRun it targets) rather than global.

### Nits

4. **`netKey` re-reads and hashes the full network file on every `/net` request — twice per part request** — `engine/cmd/demosrv/geojson.go` `part()` computes `netKey`, then calls `c.path()` which computes it again. For la-lean that's ~2 full multi-hundred-MB reads × 4 sequential part fetches per page load. Works for a dev server; an mtime-keyed memo would erase it.

5. **`isManifest` substring sniff can false-positive** — `geojson.go` `isManifest` matches `"parts"` anywhere in the first 4 KiB; a single-file net whose early content contains the literal quoted string (e.g. a lane id `parts`) gets `Cache-Control: no-store` on a huge document. Consequence is perf-only. Parsing the head for the actual top-level key (or recording manifest-ness at generation time) would be exact.

6. **demos.html now carries a third hand-copy of the palette** — `viz/demos.html` inline `PALETTES` duplicates theme.ts values (as do index.html's `:root` defaults). Comments acknowledge it, and theme.test.ts pins theme.ts only — nothing pins these copies against drift.

7. **AsyncAPI 3.0 has native request/reply** — `contracts/asyncapi.yaml:71` uses a custom `x-reply` extension; the spec's `operations.*.reply` would express the sig.req reply channel first-class.

8. **`%03d` part index** — `geojson.go` part URLs/filenames and the test regex assume ≤999 parts; `fmt` degrades gracefully to 4 digits and the handler parses it, but `TestNetCacheChunked`'s `\d{3}` regex would not. Unreachable under the 256 MiB threshold before other walls; noting only because the test encodes the narrower shape.

### Questions

9. **Interleaved complementary drops merge two rounds' chunks** — the accumulator (viz/src/tssg.ts `SignalTableAccumulator`) accepts A-round chunk 1 followed by B-round chunk 2 when drops are complementary (documented as ADR-0016's LIMITATION, harmless while tables are static). Intents are vehicle-scoped (engine/intent.go), so nothing mutates programs mid-run today — confirm the deferred `sig_gen` is tracked as a hard precondition for any future adaptive-signal work, since the failure would be a silently mixed table.

10. **Cold-cache part request regenerates the entire multi-GB part set synchronously** — `geojson.go` `part()` calls `c.path()` when the manifest is missing (e.g. cache dir wiped between the client's manifest fetch and part fetch). The first part request then pays full generation inside one HTTP request while holding `c.mu`. Intended, or should a missing manifest 404 the part (client refetches the manifest, which regenerates)?
