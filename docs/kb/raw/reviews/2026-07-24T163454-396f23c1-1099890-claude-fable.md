## Should-fix

1. **`scripts/osm-stop-nodes.py:174` — the `defaulted` count (ADR-0017 §4's stated audit signal) is inflated and orphaned stops are silently dropped.** `defaulted += 1` fires before checking whether the stop node touches any way in the extract. The Overpass node query pulls every `highway=stop` in the bbox, including ones on ways outside the kept class set (service/footway, or dropped by `overpass-lean.py`); those nodes reach this branch with `ways_at.get(nid)` empty, bump the "inferred from oneway where possible" count, then resolve to nothing. The ADR points at this count as the accountability mechanism; it currently conflates "direction defaulted" with "not on any imported way," and the latter gets no report line at all. Count `defaulted` only when the node has incident ways; report orphans separately.

2. **`scripts/import-city.sh:69` — `REPO_REV` omits `scripts/render-city.py` deliberately (fine) but also omits the rest of `engine/netimport/` package.** The hash covers `engine/netimport/netimport.go` only, but the importer's behavior is the whole package plus its module deps; a change split into a new file in that package would ship with an unchanged provenance stamp while producing different JSON — exactly the drift the stamp exists to catch. Cheap fix: `cat "$ROOT"/engine/netimport/*.go`. (Today the package is a single non-test file, so this is latent, not live.)

## Nits

3. **`scripts/osm-stop-nodes.py:226`** — a stop whose explicit `direction` fights a oneway can add arms that `incident_arms` doesn't count, so `len(arms) >= total` can spuriously promote to `allway_stop`. ADR-0017 §4 explicitly triages mapper-error tags as walked-as-tagged, so recording only.
4. **`scripts/osm-stop-nodes.py:169`** — at a split node whose two ways have opposing node order, `direction=forward` is walked forward on *both* ways (OSM direction is relative to one way), potentially marking junctions on both sides from one sign. Rare geometry; under the same mapper-ambiguity triage.
5. **`scripts/render-city.py:104-108`** — plot bounds come from non-internal lane shapes only; stop/signal markers (internal-lane `shape[0]`) at the network fringe can land outside `xlim/ylim` and clip. Cosmetic, render-only.
6. **`scripts/import-city.sh:17`** — `NAME` is interpolated unvalidated into paths and `scenario.yaml` (`id: $NAME`); a name with `/` or spaces produces confusing failures. Usage-doc territory.
