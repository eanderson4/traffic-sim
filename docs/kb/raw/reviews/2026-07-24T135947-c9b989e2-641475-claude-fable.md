## Findings

**Blockers** — none.

The `boundaries()` bucketing is state-identical to the sweep: the handled set is the same (nothing changes `v.S` mid-pass except handling itself), chained hops re-enter only strictly-lower-index buckets that cannot yet have been processed (loop index only decreases, so a bucket is never appended to after its `delete`), and no map is ever *ranged* — `past` is only indexed, so no iteration-order exposure. Bench CRC-identical corroborates.

**Should-fix**

1. `engine/cmd/metview/main.go:284-302` (`handleTrips`) — per-type means include horizon-partial trips (`Completed=false`, `ExitTick=horizon`, per metrics.go:703-704). ADR-0014 §3's drop-partials discipline is applied to intervals (main.go:196-201) but not trips, so `mean_time_s`/`mean_speed_kmh`/`mean_loss_s` are biased low/truncated for congested runs — exactly the cross-run comparison this tool exists for, and the bias scales with `active_at_horizon`, which differs between variants. Easy fix: aggregate completed trips only (the `count`/`done` columns already show the split), or add a completed-only toggle.

**Nits**

2. `engine/cmd/metview/main.go:37-50` — sink interval fields `q/k/occupancy/stops/time_loss_s` are `*float64,omitempty` (metricsjson.go:36-41, omitted when the measurement group is off); metview's non-pointer struct decodes absence as 0, so a set with a group disabled renders indistinguishable from true zeros. Fine for current files; worth a one-line comment at least, since the struct doc only warns about renames.
3. `engine/engine.go:467-468` — "exactly as the old sweep's re-scan reached them" slightly overstates: a chained crosser is appended at the bucket *tail*, whereas the old sweep re-encountered it at its `e.order` position among the successor's other past-end vehicles. Equivalent only via the order-independence argument the comment already makes; tighten the wording so a future reader doesn't take positional equivalence literally.
4. `engine/cmd/metview/main.go:127` — the `/` handler serves index.html for every path (`/favicon.ico`, typos). Guard `r.URL.Path != "/"` → 404.
5. `engine/network.go:89` — zero-value sentinel: an all-zero-length network recomputes the sum on every call. Harmless (same value), just noting the sentinel choice is load-bearing on "real networks have length."

**Questions**

6. `engine/cmd/metview/main.go:281` (summary) vs main.go:302 — summary `mean_speed_kmh` = totals VMT/VHT also includes active-vehicle travel; that's the sink's standard definition so probably intended, but if you fix finding 1, decide whether the summary row should say so (it can't be recomputed client-side).
