# Review — M11 TSSG chunking + chunked GeoJSON + demo identity (ADR-0016/0017/0018)

## Blockers

None found. The contract discipline is in order: AsyncAPI bumped to 2.3.0 with the new `state.sig.req` channel, `sig_chunk` header, and the observer-publish amendment; ADR-0016 is ratified in the same change; the legacy-reader hazard (chunk installed as whole table) is documented in both the ADR and the contract. Determinism spot-checks pass: no map iteration in publish paths (`signalProgramBodies` walks the `e.Net.Signals` slice in file order, `engine/natsio/sigframe.go:3179`-region), chunk packing is a pure function, `stopSigns` uses an insertion-ordered Map, and the only wall-clock uses are ops paths (probe/supervisor), not sim paths. `withSigTick` patches offset 8, which is correct for the TSSG header layout.

## Should-fix

1. **`engine/cmd/demosrv/supervisor.go:165` (start) — a second start blocks on `s.mu` for up to the full 660 s identity wait with no abort and no feedback.** Only `stop()` stamps `abortGen`; a queued `start` does not. UI flow: user starts la-lean (~400 s build), clicks another demo card → that POST hangs until the first start resolves. Either 409 fast ("a start is in progress") via a TryLock, or let a new start stamp the abort the way `stop()` does. The lock-free status mirror fixed `/api/status` but left the start path serialized behind the long wait.

## Nits

2. **`engine/cmd/demosrv/geojson.go` (`netKey`, `part`) — every part request reads + hashes the full network file twice** (`part()`'s `netKey`, then `path()`'s `netKey` again). At la-lean scale that's ~8 full reads/SHA-256 of a multi-hundred-MB file per page load. Measured load time (~150 s) says it's tolerable; a (path, mtime, size)→hash memo is the obvious cut if it ever matters.
3. **`engine/cmd/demosrv/main.go` (`advertisedWsURL`) — IPv6 host without a port double-brackets.** `SplitHostPort("[::1]")` fails → `reqHost = "[::1]"` → `JoinHostPort` yields `ws://[[::1]]:8443`. Only reachable with a wildcard listen behind a default-port proxy with an IPv6-literal Host; strip brackets or accept the edge.
4. **`engine/cmd/demosrv/geojson.go` (`isManifest`) — substring sniff for `"parts"` in the first 4 KiB** can false-positive on a lane id containing that string in a small single-file net. Consequence is only a spurious `Cache-Control: no-store`; fine today, worth a real JSON-prefix check if lane ids ever get free-form.
5. **`viz/src/main.ts` (`requestSig`) — a reply set that gaps then completes within one `requestMany` fires one redundant extra pull** (`retry` stays true after the success resets `sigReqRetries`). Bounded, self-terminating; cosmetic.
6. **`viz/src/main.ts` (`installSigTable`) — a completed PULL clears the broadcast accumulator's partial timer while `sigAccum` may still hold a dead partial.** Self-heals on the next 2 s broadcast round (chunk 1 reads as regression → gap → pull), so no stuck state; just noting the coupling.
7. **`viz/src/tssg.ts` (`parseSigChunkHeader`) — accepts leading zeros (`"01/2"`)** that the tightened contract pattern (`asyncapi.yaml` `^[1-9][0-9]*/...`) forbids. Lenient reader, strict writer — acceptable, arguably desirable.

## Questions

8. **Live 20-tick cadence still rebroadcasts the full chunk set** — at la-lean scale that's ~7.3 MB every 2 s (~3.7 MB/s) to every subscriber, while ADR-0016 §5 removes the paused ~1 Hz republish precisely because a full-table-per-second stream is "a firehose aimed at the busy tabs it targets." The ratified ADR keeps the cadence + pull, so this is settled as written — but is a slower cadence (or cadence-off once a client has pulled) the intended follow-up when the pull path has proven itself? Worth a line in the ADR's consequences if so.
9. **ADR-0016 §7 observer-publish amendment is doc-only** — the embedded broker runs without authorization, so "scoped to that one subject" is a statement of intent, not an enforced permission. Fine local-first (ADR-0004); flagging so it's a conscious deferral if the broker ever grows auth.

The `sig.req` reply-inbox confinement, empty-payload rejection, oversized-program fail-loud at bus construction, the per-spawn run nonce as ownership proof, and the parts-before-manifest atomic generation order are all well-reasoned and test-pinned.
