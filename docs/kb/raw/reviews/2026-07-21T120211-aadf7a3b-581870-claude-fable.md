## Review — M12 overlay implementation (variant.yaml)

Read the full patch plus `scenario.go` and the ADR-0012 M12 addendum. Note: I could not execute `go test` (sandbox denied); this is a static review.

**Blockers:** none. The implementation matches the addendum's decided grammar point-for-point (dispatch, single-level composition, node-merge semantics, null fence, anchor immutability, effective-network validation, hash framing under the conceptual merged directory), and the hash-equivalence tests pin the acceptance shape including golden vector.

**Should-fix**

1. `engine/scenario/scenario.go:517` — the new duplicate-ref check omits `m.Network`. A plain scenario with `control: [network.json]` passes validation and produces two `hashPart` entries with the same `rel` ("network.json": canonical JSON + raw bytes). `Hash()` sorts with unstable `sort.Slice` (scenario.go:329), so equal-`rel` frames have unspecified relative order — hash stability across Go toolchain versions is not guaranteed for such a directory. The variant path fences this via `baseRefs` (variant.go:284-298), so plain scenarios are now *weaker* than variants on the stated "one hash frame per rel path" rule. One-line fix: seed `seenRefs` with `m.Network`.

2. `engine/scenario/variant_test.go` — no test exercises the (part path, flow id) anchor namespacing this addendum explicitly resolved: two base demand parts each containing flow id `X`, patch names one part, only that part's flow changes. All patch tests use a single-part base. Cheap test, core new semantic.

**Nits**

3. `engine/scenario/variant.go:256` — the single-level chaining check uses `err == nil` only; a non-`ErrNotExist` stat error silently skips it, contradicting the fail-loud dispatch discipline documented at scenario.go:157. No behavior hole (the subsequent `Load(baseDir)` re-stats fail-loud), but the inconsistency invites copy-paste of the weaker pattern.

4. `engine/scenario/variant.go:278` — `types: []` (present, empty) counts as an override (`v.Types != nil`) and then `validateManifest` silently defaults it back to `[car]`. An overlay author writing `types: []` gets an implicit default rather than a loud error; consider rejecting empty-present.

5. `engine/scenario/variant_test.go:784` — `TestVariantSequenceReplace` rewrites `demand/main.yaml` with the identical content `variantPair` already wrote; dead line under a load-bearing-looking comment.

**Questions**

6. `variant.go:461` — `base` allows unbounded `../` traversal (no physical confinement analogous to `resolvePart`'s symlink fence). The addendum says "../ allowed" so I read this as decided; flagging only to confirm arbitrary-depth escape (outside the repo) is intended.

**Contract/ADR:** clean — no NATS surface touched, the ADR-0012 M12 addenda (design + implementation notes) are staged alongside, `gopkg.in/yaml.v3` stays confined to `engine/scenario/`, and the duplicate-ref tightening in `validateManifest` only rejects previously-degenerate directories (dup refs double-hashed and double-spawned flows), which is fail-loud consistent.

**Determinism:** no wall clock, no RNG, no map-order leaks in sampled paths — `patchesByPart` iteration only feeds a sorted error message (variant.go:399-402), patches apply in authored order, and hash framing is sorted by rel (modulo finding 1).
