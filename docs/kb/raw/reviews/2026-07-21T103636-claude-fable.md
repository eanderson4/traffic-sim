Review of the staged diff (review-gate tooling: `hooks/pre-commit`, `scripts/external-review.sh`, AGENTS.md/SKILL.md docs). No blockers; the design is sound — stamp-the-captured-patch is genuinely TOCTOU-safe and fail-closed. Findings:

**should-fix**

1. **Rename-out-of-scope bypasses the gate** — `hooks/pre-commit:82-83`. `git diff --cached --name-only` lists only the *destination* path for detected renames, and `diff.renames` defaults to on (unset in this repo). Renaming `engine/foo.go` → `docs/foo.go` (i.e., removing a gated file) shows only `docs/foo.go`, matches nothing, and the commit passes ungated. Add `--no-renames` so renames surface as A+D pairs with both paths listed.

2. **`T` (typechange) missing from `--diff-filter=ACMRD`** — `hooks/pre-commit:82`. A file→symlink (or reverse) change under `engine/` etc. is filtered out of the name list and skips the gate. Cheap fix: `ACMRDT`.

3. **Stamp hash is sensitive to dynamic hash abbreviation and diff config** — `scripts/external-review.sh:149` and `hooks/pre-commit:87`. The stamp equality relies on `git diff --cached` producing byte-identical output at review time and commit time. The `index abc123..def456` lines use auto-scaled abbreviation (`core.abbrev` unset here): any operation that grows the object db between review and commit (e.g., `git add`ing the archive files, then unstaging) can lengthen the abbreviation and fail the gate on an unchanged diff — a confusing false negative. User diff config (`diff.noprefix`, `diff.algorithm`, `color.diff=always`) is a smaller version of the same fragility. Pin both invocations identically, e.g. `git -c core.abbrev=40 diff --cached --full-index --no-color` (or at minimum `--full-index`) in both the capture and the hook. Fail-closed, so annoyance not vulnerability — but it will bite exactly during the "commit the archive separately" flow the script itself recommends.

**nit**

4. **Archive loss on late failure** — `scripts/external-review.sh:147,208-213`. `keep=1` is only set on reviewer failure. If `mkdir`/`cp` in the archive step fails under `set -e`, the EXIT trap deletes `$work` and both completed reviews are lost. Set `keep=1` before the archive section (or after reviews succeed).

5. **Same-second timestamp collision silently overwrites archives** — `scripts/external-review.sh:144,210-213`. `%Y-%m-%dT%H%M%S` has 1s resolution and `cp` clobbers. Unlikely, but the archive is the audit record; append a short random/hash suffix (e.g., first 8 chars of the diff hash — also makes archive↔stamp correlation explicit).

6. **"Reviewer succeeded" = exit 0 + non-empty stdout** — `scripts/external-review.sh:189-194`. A CLI that prints a login banner or "usage" to stdout with exit 0 stamps the diff as reviewed. A minimal sanity check (output length threshold, or grep for a required marker the brief asks reviewers to emit) would harden this.

7. **Drift path ends with "commit now"** — `scripts/external-review.sh:203-206,222`. When drift is detected the script warns correctly but still prints the success epilogue including "commit now". Track drift in a flag and swap the final message (or exit nonzero) so the two messages don't contradict.

8. **Nothing detects an unset `core.hooksPath`** — the gate silently doesn't exist on a fresh clone until `git config core.hooksPath hooks` is run (it is set in this clone). The script could check and warn: "stamping, but the hook isn't enabled in this clone."

**question**

9. **Merge commits**: concluding a conflicted merge runs pre-commit with the entire merge staged, so the gate will demand external review of the full merge diff. Intended? Probably acceptable (merges into gated paths arguably *should* be reviewed), but worth deciding deliberately before it surprises someone.

On the focus areas from the brief: no determinism risks (shell tooling only; `date` use is archival naming, not engine state), no NATS subject/payload changes, and the AGENTS.md change is consistent with the two-tier design (CLAUDE.md is a symlink to AGENTS.md, so it's covered). The self-gating choice — `scripts/` and `hooks/` are themselves in the gated set — is correct and this very diff would be subject to it.
