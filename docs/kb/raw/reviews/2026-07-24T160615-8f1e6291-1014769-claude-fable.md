## Findings

**Blockers** — none. No NATS subject or payload changes; `network-format-v1.md` edits are recipe docs only; the `Imported` field pre-exists, the new flag only pins its value; ADR-0017 covers the consequential import decisions per rule 3.

**Should-fix**

1. `engine/cmd/netimport/main.go:43-46` — `-imported` is never validated. A malformed stamp (typo, or garbage from the Overpass `timestamp_osm_base` path) flows silently into the canonical network JSON and hence the ADR-0012 content hash. The flag's whole point is reproducible provenance; one `time.Parse(time.RFC3339, stamp)` with a fatal error keeps garbage out of hashed bytes.
2. `scripts/import-city.sh:47` — `$SRC` is interpolated into a single-quoted Python string literal. A path containing `'`, backslash, or other Python-string metacharacters makes the extraction fail; the `|| true` then *silently* drops `-imported`, so netimport falls back to `time.Now()` and the import is stamped "OSM base unknown" — reproducibility degrades with no visible error. Pass the path via `sys.argv[1]` instead of string splicing.

**Nits**

3. `scripts/import-city.sh:50` — `REPO_REV=$(git rev-parse --short HEAD)` stamps provenance with a commit that may not contain the scripts doing the import (this very run would stamp the pre-commit HEAD, and dirty trees generally). Consider appending `-dirty` when `git status --porcelain` is non-empty.
4. `scripts/import-city.sh:48` / `"${IMPORTED_ARGS[@]}"` at line 56 — empty-array expansion under `set -u` errors on bash < 4.4 (macOS stock 3.2). Fine for this repo's Linux local-first stance; noting for portability.
5. `scripts/overpass2osm.py:39` — comment says "first occurrence wins" but the code merges tags preferring the later element (correctly, per the fuller comment below). Stale half-comment.
6. `scripts/osm-stop-nodes.py:216-218` (`incident_arms` vs walk arms) — contradictory OSM data can make `len(arms) > total`: e.g. `direction=backward` on a stop sitting on a `oneway=yes` way walks *against* travel to the entry-end junction and records an arm that `incident_arms` counts as 0, potentially tipping an unrelated junction to spurious `allway_stop`. Data-error-only; a `min`/clamp or a stderr warning would make it visible. Not worth hardening beyond that per the triage bar.

**Questions**

7. `scripts/import-city.sh:33-38` — pass 2 re-runs netconvert without `--proj.utm`; correct because the `.net.xml` carries its `<location>` block, but worth one comment line since the asymmetry with pass 1 looks like an omission.
8. `scripts/osm-stop-nodes.py` walk determinism — `nxt.pop()` on a set is order-dependent in general, but `is_split` guarantees exactly 2 ways at the hop node and the current way is always in `seen`, so the candidate set is ≤1 element and output is deterministic (plus `render` sorts). Confirmed fine; flagging only so nobody relaxes `is_split` to ≥2-way splits without noticing the latent nondeterminism.
