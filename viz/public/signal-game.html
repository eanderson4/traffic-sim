Beat the Signal — Bottleneck Town

Retune the four traffic lights on Main Street and beat the town's own timing. A fictitious network, measured honestly.

The rules

  • Same network, same demand, same seed (seed 42, 15,000 ticks ≈ 25 min of traffic). The only thing that changes between runs is the light timing.
  • Each of the four junctions J1–J4 runs a 4-phase cycle: Main St through+right, Main St protected lefts, cross street northbound, cross street southbound. You set the four green durations; amber (3 s) and all-red (2 s) are fixed, so cycle = your greens + 20 s.
  • Round 2 adds offsets: how many seconds into the simulation a junction's first green begins. Offsets are how you build a green wave.
  • Bounds: each green 5–90 s, each junction's cycle 40–150 s, offset below the cycle length. The compiler enforces the same bounds.
  • Score: mean time loss per vehicle (lower is better) and trips completed, from the run's own metrics. The bars to beat are the shipped arms: base (86 s fixed-time), retime-short (66 s), and green-wave (eastbound progression).
